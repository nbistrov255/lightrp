## 2. Смысл цветов в задачах (строго)

| Приоритет | Цвет | Подпись |
|---|---|---|
| urgent | `--bad` (красный) | Срочно |
| high | `--warn` (оранжевый) | Высокий |
| normal | `--accent` (фиолетовый) | Обычный |
| low | `--surface-3` / muted (серый) | Низкий |

| Статус | Тон бейджа | Подпись |
|---|---|---|
| open | info (бирюзовый `--accent-2`) | Новая |
| in_progress | accent | В работе |
| review | warn | На проверке |
| done | ok | Выполнена |
| rejected | bad | На доработке |

Бейдж: `inline-flex items-center gap-1 rounded-full px-2 py-0.5 text-[12px] font-semibold` + тон `bg-{цвет}/15 text-{цвет}` (нейтральный: `bg-surface-3 text-muted`).
Метка общей задачи (без исполнителя): бейдж «Общая», тон info.
Баллы всегда зелёные (`text-ok`) со знаком «+». Просроченный дедлайн — `text-bad font-semibold` и префикс «Просрочено ·».

## 3. Экран «Список задач»

### Шапка страницы
- Строка `flex items-end justify-between gap-3 mb-4`:
  - слева H1 «Задачи» — `text-[26px] md:text-3xl font-extrabold tracking-tight`, под ним подзаголовок `text-sm text-muted`:
    - админ: «Ваши задачи и общие задачи смены»

  - справа (только директор) — primary-кнопка с иконкой `Plus`: на ПК «Новая задача», на телефоне «Создать».
- Админ кнопку создания **не видит**.

### Фильтры
Сегментный переключатель (не табы с подчёркиванием):
```
контейнер: flex gap-1 p-1 rounded-2xl bg-surface-2 border border-line
пункт:     flex-1 h-9 px-3 rounded-xl text-sm font-semibold
активный:  bg-surface text-text shadow-sm border border-line
остальные: text-muted hover:text-text
```
Пункты: «Активные» · «На проверке» (со счётчиком-кружком `min-w-5 h-5 rounded-full text-[11px]`, на активном пункте `bg-accent text-white`, иначе `bg-surface-3`) · «Готово».
У директора рядом второй переключатель «Все / Мои». Телефон — переключатели друг под другом, ПК (`sm:`) — в строку, первый растягивается.

### Карточка задачи
```
Card  relative overflow-hidden pl-5   (кликабельная: hover:border-accent/40 active:scale-[.99], cursor-pointer)
├─ полоса приоритета: absolute left-0 top-0 bottom-0 w-1.5, цвет по приоритету
├─ строка бейджей (flex flex-wrap gap-1.5 mb-1.5):
│     [приоритет] [статус — если не «Новая»] [«Общая» — если без исполнителя]
├─ название: font-bold text-[16px] leading-snug

справа сверху (только у директора): аватар исполнителя 32px — круг с инициалами на градиенте, цвет из хэша имени
```
Даты относительные: «Сегодня», «Завтра», «Вчера», иначе «ср, 25 нояб.»; время 24ч.

### Сетка и порядок
- Телефон: одна колонка, `gap-3`.
- ПК (≥768px): `grid md:grid-cols-2 gap-3`.
- Порядок: срочные → высокие → обычные → низкие; внутри — по ближайшему дедлайну.

### Пустые состояния (по центру, py-12)
Плашка-иконка `size-14 rounded-3xl bg-surface-2 text-muted` с `ListChecks`, заголовок bold, текст `text-sm text-muted`:
- «Задач нет» + «Новые задачи появятся здесь и в уведомлениях»
- на вкладке «На проверке»: «Нечего проверять»
Загрузка — спиннер `Loader2 animate-spin text-accent` по центру. Ошибка — карточка `border-bad/30 bg-bad/5` с текстом и кнопкой «Повторить».

8. **Блок действия** — зависит от роли и статуса (см. п. 5).

## 5. Блок действия по состояниям

### Администратор, статус open / in_progress / rejected (задача его или общая)
Заголовок секции: «Выполнение» (или «Доработать и сдать снова» при rejected). Карточка `space-y-4`:
- (только open) secondary-кнопка на всю ширину h-11 «Взять в работу» с иконкой `Play`.
- «Фото результата (обязательно)» — подпись с иконкой Camera; ниже выбор фото:
  плитки 80×80 `rounded-2xl`; плитка добавления `border-2 border-dashed border-line text-muted hover:text-accent hover:border-accent/50`, внутри Camera + «Добавить фото» 10px; превью с кнопкой-крестиком `size-6 rounded-full bg-black/70` в углу. На телефоне открывается камера (`capture="environment"`), фото сжимаются перед загрузкой.
- «Комментарий» — textarea 3 строки, плейсхолдер «Что сделано, нюансы».
- Primary-кнопка **lg (52px) на всю ширину** «Сдать на проверку» с иконкой `Send`. Неактивна (opacity 50 %), пока для задачи с обязательным фото не добавлено ни одного фото.
Успех → тост сверху «Отправлено на проверку», статус меняется на «На проверке».

### Администратор, статус review
Блока действия нет — виден отчёт и бейдж «На проверке».

### Администратор, статус done
Комментарий директора в зелёной карточке, отчёт, бейдж «Выполнена».

### Директор, статус review
Заголовок секции «Проверка». Карточка `space-y-4`:
- textarea «Комментарий», плейсхолдер «Что хорошо / что исправить»;
- поле «Начислить баллов» (число), плейсхолдер = баллы задачи, подсказка «По умолчанию — 20»;
- две кнопки `grid grid-cols-2 gap-2`: слева danger «На доработку» (`RotateCcw`), справа success «Принять» (`Check`).
  danger = `bg-bad/12 text-bad border border-bad/25`, success = `bg-ok/12 text-ok border border-ok/25`.

## 6. Форма «Новая задача / Редактировать» (только директор)

Не отдельная страница, а **шторка**:
- Телефон: снизу, на всю ширину, `rounded-t-[28px]`, высота до 92 %, ручка-полоска `h-1.5 w-10 rounded-full bg-surface-3` сверху.
- ПК: диалог по центру `max-w-lg` (512px), `rounded-[28px]`, без ручки.
- Фон за шторкой `bg-black/60 backdrop-blur-sm`, Esc и клик по фону закрывают.
- Шапка: «Новая задача» `text-lg font-bold` + крестик справа. Тело прокручивается, `px-5 space-y-4`.

Поля по порядку:
1. «Что нужно сделать» — input, автофокус, плейсхолдер «Например: почистить кулеры в VIP».
2. «Описание» — textarea, «Детали, критерии готовности».
3. «Приоритет» — **не select**, а 4 кнопки `grid grid-cols-4 gap-1.5`, каждая `h-10 rounded-xl text-sm font-semibold border`: Низкий · Обычный · Высокий · Срочно. Выбранная заливается цветом смысла: Срочно `bg-bad text-white`, Высокий `bg-warn text-black`, Обычный `bg-accent text-white`, Низкий `bg-surface-3`. Невыбранные `bg-surface-2 border-line text-muted`.
4. В строку (`grid grid-cols-2 gap-3`, и на телефоне тоже): «Зона» (select из зон клуба, первый пункт «Не указана») и «Баллы за выполнение» (число, по умолчанию 10).
5. «Исполнитель» — select, первый пункт «Любой администратор (общая)».
6. «Дедлайн» — datetime-local.
7. Тумблер «Фотоотчёт обязателен» (по умолчанию включён): трек `h-7 w-12 rounded-full`, вкл `bg-accent`, белый кружок `size-6`.

Поля: `h-11 rounded-2xl bg-surface-2 border border-line px-3.5 text-[15px]`, фокус `border-accent ring-4 ring-accent/15`; подпись над полем `text-[13px] font-semibold text-muted mb-1.5`.
Футер шторки закреплён (`border-t border-line px-5 pt-3 pb-5` + safe-area): одна primary-кнопка lg на всю ширину «Создать задачу» / «Сохранить», неактивна без названия.

## 8. Анимации и отклик

- Нажатие: кнопки `active:scale-[.97]`, карточки `active:scale-[.99]`, иконки-кнопки `active:scale-95`; переходы цвета 150ms.
- Шторка появляется снизу: translateY(24px)→0 + fade, 220ms, `cubic-bezier(.2,.8,.2,1)`.
- Кнопка в загрузке: иконка заменяется на крутящийся `Loader2`, кнопка неактивна.
- Каждое действие подтверждается тостом сверху по центру (`rounded-2xl bg-surface border shadow-2xl`, иконка `CheckCircle2` ok или `AlertTriangle` bad, исчезает через 3 с).
- Никаких скелетонов и долгих анимаций — интерфейс должен ощущаться мгновенным.
