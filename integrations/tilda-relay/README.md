# Ретранслятор броней Tilda → Discord + CyberHub Control

**Зачем.** Если Tilda отправляет заявки прямо в приложение, то пока сервер перезагружается или недоступен, заявки теряются — и в Discord тоже ничего не приходит. Ретранслятор работает на серверах Google (бесплатно, без своего сервера) и:

1. **Сразу** записывает заявку в Google Таблицу (лист «Брони») — это ещё и резервный журнал всех броней.
2. **Сразу** отправляет её в Discord.
3. **Сразу** передаёт в CyberHub Control. Если приложение недоступно — повторяет каждые 5 минут (до суток), пока не доставит. Дубли исключены по `tranid` Tilda.
4. Если Discord временно не ответил — тоже повторит.

## Установка (≈ 10 минут)

1. Создайте новую Google Таблицу, например «CyberHub — брони».
2. **Расширения → Apps Script**. Удалите содержимое `Code.gs` и вставьте код из [`Code.gs`](Code.gs). Сохраните.
3. **Project Settings (⚙️) → Script properties → Add script property:**

   | Свойство | Значение |
   |---|---|
   | `RELAY_TOKEN` | любая длинная случайная строка (для URL вебхука) |
   | `DISCORD_WEBHOOK` | URL вебхука канала броней в Discord |
   | `APP_URL` | `https://<домен приложения>/api/integrations/tilda` |
   | `APP_TOKEN` | значение `TILDA_TOKEN` из `.env` приложения |

4. В редакторе выберите функцию **`setup`** → **Run**. Разрешите доступ (таблица, внешние запросы, триггеры). Создастся лист «Брони» и триггер повтора.
5. **Deploy → New deployment → Web app**: *Execute as* — **Me**, *Who has access* — **Anyone**. Скопируйте URL вида `https://script.google.com/macros/s/…/exec`.
6. Проверка: выберите функцию **`testBooking`** → Run. В Discord и в приложении должна появиться бронь «Тест».

## Подключение в Tilda

Для **каждого** сайта (RU и LV): Настройки сайта → **Формы** → **Webhook** → URL:

```
RU:  https://script.google.com/macros/s/…/exec?token=<RELAY_TOKEN>&lang=ru
LV:  https://script.google.com/macros/s/…/exec?token=<RELAY_TOKEN>&lang=lv
```

Затем в настройках каждой формы бронирования отметьте этот приёмщик данных и переопубликуйте страницы.

### Названия полей формы
Ретранслятор и приложение распознают поля по названию (в Tilda — «Имя переменной» поля), на русском, латышском или английском:

| Что | Подходящие имена переменных |
|---|---|
| Имя | `Name`, `Имя`, `Vārds` |
| Телефон | `Phone`, `Телефон`, `Tālrunis` |
| E-mail | `Email`, `E-pasts` |
| Дата | `Date`, `Дата`, `Datums` |
| Время | `Time`, `Время`, `Laiks` |
| Гостей / ПК | `Guests`, `Количество`, `Skaits` |
| Зона | `Zone`, `Зона`, `Zāle` |
| Комментарий | `Comment`, `Комментарий`, `Komentārs` |

Остальные поля не теряются — они видны в карточке брони в приложении.

## Если обновили код
После изменений `Code.gs`: Deploy → **Manage deployments** → ✏️ → Version: *New version* → Deploy. URL не меняется.

## Диагностика
* Колонки «Discord» / «Приложение» в листе «Брони» показывают статус доставки, «Ошибка» — причину.
* Apps Script → **Executions** — журнал запусков.
