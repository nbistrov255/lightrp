# CyberHub Control

Внутреннее приложение для директора и администраторов компьютерного клуба **CyberHub** (Рига).
Сначала под телефон (пользоваться на смене), полноценная версия для компьютера, устанавливается на телефон как приложение (PWA).

## Что умеет

| Раздел | Возможности |
|---|---|
| **Аккаунты** | Личные входы сотрудников и директора, роли «Директор» / «Администратор», сессия 30 дней, смена пароля, защита от перебора паролей |
| **Смены** | Автоматическая синхронизация из Google Таблицы каждые 15 минут, недельный график, «кто сейчас на смене», ручные замены |
| **Задачи** | Дедлайны, приоритеты (срочно / высокий / обычный / низкий), зоны клуба, баллы, обязательный фотоотчёт, сдача на проверку → директор принимает или возвращает на доработку |
| **Чек-лист смены** | Стартовая проверка клуба: пункты с обязательными фото, прогресс, история, баллы за выполнение. Пункты настраивает директор |
| **Поломки** | Журнал с оборудованием (ПК-12, VIP-3…), важностью, фото до/после, статусами «новая → в ремонте → исправлено» |
| **Касса** | Ежедневный отчёт: остаток, наличные, карта, расходы, выемка в конверт, автоматический расчёт расхождения. Проверка директором |
| **Конверты** | Учёт наличных по конвертам (сейф, инкассация, зарплаты…): приход, расход, перекладывание, история движений |
| **Авансы** | Запрос сотрудника → директор одобряет / отклоняет / выдаёт (со списанием из конверта) |
| **Баллы** | Начисления за задачи и чек-листы, бонусы и штрафы, рейтинг месяца, обмен баллов на деньги с согласованием директора |
| **Брони** | Заявки с русской и латышской версий сайта на Tilda, дублирование в Discord, звонок / WhatsApp в одно касание, ручные брони по телефону |
| **Уведомления** | В приложении (колокольчик) + Discord: поломки, кассовые отчёты, авансы, срочные задачи, брони |

## Архитектура

```
 Tilda RU ─┐                      ┌──► Discord #брони        (сразу)
           ├──► Ретранслятор ─────┼──► Google Таблица «Брони» (журнал + очередь)
 Tilda LV ─┘   (Google Apps       └──► CyberHub Control       (сразу; если недоступен — повтор каждые 5 мин)
                Script)

 Google Таблица смен ──CSV──► CyberHub Control ──► Discord #общий
                               │
                               └── SQLite + фото на диске
```

* **server/** — Node.js 22 + Express 5, встроенный SQLite (`node:sqlite`, без нативных модулей), JWT в httpOnly-cookie, загрузка фото через multer.
* **client/** — React 19 + TypeScript + Tailwind CSS 4 + Vite. Mobile-first, тёмная и светлая темы, PWA (manifest + service worker). Фото сжимаются на телефоне перед отправкой (≈ 5 МБ → 300 КБ).
* **integrations/tilda-relay/** — ретранслятор броней на Google Apps Script. Работает на серверах Google, поэтому брони попадают в Discord, **даже если CyberHub Control выключен или обновляется**. См. [его README](integrations/tilda-relay/README.md).

## Быстрый старт (локально)

Нужен Node.js ≥ 22.13.

```bash
npm install
cp .env.example .env          # для локального запуска можно оставить пустым
npm run seed -- --demo        # директор director / cyberhub + демо-сотрудники anna, mark, liga (пароль admin123)
npm run dev                   # API :3000, интерфейс http://localhost:5173
```

Без `--demo` создаётся только директор, базовый чек-лист и конверты.

## Запуск на сервере

Для Tilda и ретранслятора приложению нужен публичный HTTPS-адрес. Самый простой вариант — небольшой VPS (Hetzner, DigitalOcean и т. п.) с Docker:

```bash
cp .env.example .env && nano .env        # JWT_SECRET, TILDA_TOKEN, вебхуки Discord, ссылка на таблицу
nano Caddyfile                           # ваш домен, например control.cyberhub.lv (A-запись → IP сервера)
docker compose up -d --build
docker compose exec app node --disable-warning=ExperimentalWarning server/src/seed.js
```

Caddy сам получит HTTPS-сертификат. База и фото лежат в томе `cyberhub-data` — его и нужно бэкапить (файл `cyberhub.db` + папка `uploads`).

Без Docker: `npm ci && npm run build && npm start` (за любым обратным прокси с HTTPS).

## Настройка интеграций

### 1. Discord
Настройки канала → Интеграции → Вебхуки → «Новый вебхук» → скопировать URL.
* `DISCORD_WEBHOOK_BOOKINGS` — канал броней
* `DISCORD_WEBHOOK_GENERAL` — общий канал (поломки, касса, авансы, срочные задачи)

Проверка: «Настройки» → «Проверить Discord» (под директором).

### 2. Google Таблица смен
Лист с колонками (порядок любой, регистр не важен, есть синонимы на LV/EN):

| Дата | Сотрудник | Начало | Конец | Комментарий |
|---|---|---|---|---|
| 24.11.2026 | Анна | 10:00 | 18:00 | |
| 24.11.2026 | Марк, Līga | 18:00 | 02:00 | ночь |

Вместо «Начало/Конец» можно одну колонку **«Время»** со значением `10:00-18:00`. Даты — `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`.

Файл → Поделиться → **Опубликовать в интернете** → выбрать лист → формат **CSV** → ссылку в `SHIFTS_CSV_URL`.
Сотрудник привязывается по полю «Имя в Google Таблице смен» в разделе «Команда».

> Если у вас график в другом виде (например, сетка «дни × сотрудники»), пришлите пример — парсер легко адаптировать.

### 3. Брони с Tilda
Подробная инструкция — в [integrations/tilda-relay/README.md](integrations/tilda-relay/README.md). Коротко:
1. Создать Google Таблицу, вставить `Code.gs` в Apps Script, задать свойства, запустить `setup`, опубликовать как веб-приложение.
2. В Tilda (RU и LV сайты) подключить приёмщик данных **Webhook** с URL ретранслятора и `&lang=ru` / `&lang=lv`.

Можно подключить Tilda и напрямую к приложению — `https://<домен>/api/integrations/tilda?token=<TILDA_TOKEN>&lang=ru` — но тогда при недоступности приложения заявка не попадёт в Discord. Ретранслятор этот риск закрывает.

## Установка на телефон
Откройте адрес приложения:
* **Android / Chrome** — меню → «Установить приложение» (или кнопка в «Настройках»).
* **iPhone / Safari** — «Поделиться» → «На экран “Домой”».

## Структура

```
server/src/
  index.js            точка входа, раздача собранного клиента
  db.js               схема SQLite (создаётся автоматически)
  auth.js             сессии и роли
  discord.js          отправка в Discord
  notify.js           уведомления в приложении + Discord
  shiftsSync.js       импорт смен из Google Таблицы (CSV)
  seed.js             первичная настройка / демо-данные
  routes/             auth, tasks, shifts, checklists, breakdowns, cash, money, bookings, misc
client/src/
  pages/              экраны
  components/         UI-кит (кнопки, карточки, шторки, фото), навигация
  lib/                API-клиент, форматирование, хуки
integrations/tilda-relay/   Google Apps Script
```
